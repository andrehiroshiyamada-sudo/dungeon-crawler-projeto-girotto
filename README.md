História do Jogo

Em um antigo calabouço esquecido pelo tempo, uma força maligna despertou e começou a espalhar monstros por toda a região. Como um aventureiro corajoso, sua missão é atravessar três fases repletas de perigos, armadilhas e inimigos para chegar até o coração do calabouço.

Durante a jornada, será necessário encontrar chaves para abrir portas, ativar botões para desbloquear caminhos e derrotar monstros que tentam impedir seu avanço. Ao final da terceira fase, você enfrentará o terrível Boss Final, responsável por toda a corrupção do local.

Somente derrotando o Boss Final será possível restaurar a paz e concluir a aventura.

Objetivo do Jogo

O objetivo é explorar as três fases do calabouço, superar obstáculos, derrotar inimigos e eliminar o Boss Final para vencer o jogo.

Como Jogar
Controles
Tecla	Ação
W	Move o jogador para cima e altera o símbolo para ^
A	Move o jogador para a esquerda e altera o símbolo para <
S	Move o jogador para baixo e altera o símbolo para v
D	Move o jogador para a direita e altera o símbolo para >
I	Interage com o objeto à frente do jogador
O	Ataca a célula à frente do jogador

Observação: Não existe movimentação diagonal.

Significado dos Símbolos
Jogador
Símbolo	Significado
<	Jogador olhando para a esquerda
^	Jogador olhando para cima
>	Jogador olhando para a direita
v	Jogador olhando para baixo
Cenário
Símbolo	Significado
-	Parede (não pode ser atravessada)
#	Espinho (causa morte instantânea)
k	Caixa (bloqueia passagem, pode ser destruída com ataque)
O	Botão (executa uma ação quando pressionado)
D	Porta fechada
@	Chave (permite abrir portas fechadas)
=	Porta aberta
L	Escada para a próxima fase
Inimigos
Símbolo	Significado
X	Monstro Tipo 1
Y	Monstro Tipo 2
Z	Boss Final
