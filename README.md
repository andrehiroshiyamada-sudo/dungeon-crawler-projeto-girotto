## História do Jogo

Em um antigo calabouço esquecido pelo tempo, uma força maligna despertou e passou a espalhar monstros por toda a região. Como um aventureiro corajoso, sua missão é atravessar três fases repletas de perigos, armadilhas e inimigos para chegar até o coração do calabouço.

Durante a jornada, será necessário encontrar chaves para abrir portas, ativar botões para desbloquear caminhos e derrotar monstros que tentam impedir seu avanço. Ao final da terceira fase, você enfrentará o terrível Boss Final, responsável por toda a corrupção do local.

Somente derrotando o Boss Final será possível restaurar a paz e concluir a aventura.

## Objetivo do Jogo

O objetivo é explorar as três fases do calabouço, superar obstáculos, derrotar inimigos e eliminar o Boss Final para vencer o jogo.

## Como Jogar

### Controles

| Tecla | Ação                                                     |
| ----- | -------------------------------------------------------- |
| W     | Move o jogador para cima e altera o símbolo para ^       |
| A     | Move o jogador para a esquerda e altera o símbolo para < |
| S     | Move o jogador para baixo e altera o símbolo para v      |
| D     | Move o jogador para a direita e altera o símbolo para >  |
| I     | Interage com o objeto que está à frente do jogador       |
| O     | O jogador realiza um ataque na célula à sua frente       |

**Observação:** Não existe movimentação diagonal.

## Significado dos Símbolos

### Jogador

| Símbolo | Significado                     |
| ------- | ------------------------------- |
| <       | Jogador olhando para a esquerda |
| ^       | Jogador olhando para cima       |
| >       | Jogador olhando para a direita  |
| v       | Jogador olhando para baixo      |

### Cenário

| Símbolo | Significado                                                         |
| ------- | ------------------------------------------------------------------- |
| -       | Parede: o jogador não pode passar                                   |
| #       | Espinho: o jogador morre ao passar por cima                         |
| k       | Caixa: o jogador não pode passar, mas pode ser destruída com ataque |
| O       | Botão: executa uma ação ao ser pressionado                          |
| D       | Porta fechada: o jogador não pode passar                            |
| @       | Chave: abre uma porta fechada ao interagir                          |
| =       | Porta aberta: o jogador pode passar                                 |
| L       | Escada: leva o jogador para a próxima fase                          |

### Inimigos

| Símbolo | Significado    |
| ------- | -------------- |
| X       | Monstro Tipo 1 |
| Y       | Monstro Tipo 2 |
| Z       | Boss Final     |

## Fases do Jogo

### Fase 1

O jogador inicia sua aventura explorando os primeiros corredores do calabouço, enfrentando obstáculos simples e os primeiros monstros.

### Fase 2

Os desafios aumentam. Novas armadilhas e inimigos tornam a exploração mais difícil, exigindo maior atenção do jogador.

### Fase 3

A última fase apresenta os maiores desafios do calabouço, com caminhos mais perigosos e uma grande quantidade de inimigos.

### Boss Final

Ao final da terceira fase, o jogador enfrentará o Boss Final (Z). A vitória só será alcançada após derrotá-lo.
